This is the first post on the new site. I've been meaning to set up a proper writing space for a while, and I finally stopped procrastinating.

## Why bother

I find that writing forces me to think more carefully. Plenty of things I was confident I understood turn out to be blurry once I try to explain them clearly. A post that never ships is still worth writing.

The other reason: I spend a lot of time reading other people's sites. It seems fair to contribute something back.

## What you can expect here

Mostly technical writing — systems, tools, the occasional rabbit hole. Shorter notes when I don't have enough for a full post. No fixed schedule.

## How the site works

Built with Astro, Tailwind v4, and MDX. Content lives in the repo as markdown files. No CMS, no database, no admin UI. Deployed via Docker on Coolify. The source is on GitHub if you're curious.

Math works too, courtesy of KaTeX:

$$
E = mc^2
$$

And code blocks get proper syntax highlighting:

```typescript
const greet = (name: string): string => `Hello, ${name}`;
console.log(greet("world"));
```

That's it for now.
